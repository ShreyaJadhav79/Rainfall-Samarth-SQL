# 🌧️ Rainfall-Samarth-SQL

Welcome to **Rainfall-Samarth-SQL**, a SQL-based prototype project for analyzing rainfall patterns across Indian states!  
This project is built using **MySQL Workbench** and open government data from [data.gov.in](https://data.gov.in/catalog/rainfall).  

It is designed as a **portfolio submission for Bharat Digital Fellowship 2026** and showcases how real-world public datasets can be structured, analyzed, and used to answer meaningful questions about rainfall trends and patterns.

---

## 🏗️ Project Overview

This project demonstrates **SQL-based data analysis** for answering rainfall-related questions, aligned with the Project Samarth challenge:

1. **Data Collection** – Rainfall dataset from IMD via data.gov.in (monthly rainfall for Indian states).  
2. **Data Storage** – Stored in a MySQL table called `rainfall_data`.  
3. **Data Analysis** – Used SQL queries to:  
   - Compare average rainfall between states  
   - Identify peak rainfall months  
   - Analyze yearly trends  
   - Compare rainfall across multiple states  
4. **Q&A Prototype** – Queries designed to answer sample questions about state-wise rainfall, trends, and policy-related analysis.

---

## 🧩 Key Objectives

- Analyze **rainfall patterns** using open government datasets.  
- Compare rainfall trends between states and over years.  
- Identify months and states with **highest or lowest rainfall**.  
- Build a **functional SQL-based Q&A prototype** that can answer Project Samarth style questions.
